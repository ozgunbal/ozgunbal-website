Truthy and Falsy

Falsy values:

  • "" (empty string)
  • 0, -0, +0, NaN
  • null, undefined
  • false

truthy values:

anything except above

Equality

  • == (only value)
  • === (value and type)
  • !=  (only value)
  • !== (value and type)

Do not check equality of objects, arrays etc. with ==/===

It doesn't consider their values only reference
